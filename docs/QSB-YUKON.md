# Taskmarket × Yukon: заказ на $199 «Quantum-Safe Bitcoin» — честный разбор

Разбор сделан 17.09.2026 по живым данным: страница задачи на Taskmarket, публичное
зеркало челленджа (github.com/Layr-Labs/quantum-safe-bitcoin-challenge) и таблица
рекордов Yukon (yukon.org/qsb). Решение фермы: **заказ не берём** — причины ниже
числами, а не словами.

## Что за заказ

Пулы 199 USDC на Base (до работников доходит ~184 USDC), делятся пропорционально
очкам. Очки даются не за участие, а за **положительный прирост** официального
рекорда: `points = 100 × (оценка − предыдущий рекорд) / рекорд`, то есть 1% сверху
рекорда = 1 очко. Две дорожки, у каждой свой рекорд:

* `pinning` — задача b352879c-669f-44ef-98cd-ad3d34d0fefa;
* `subset` — задача eafd2f3d-e64f-49c1-b98a-6b825b0cdc82.

Сроки (UTC): код — 7 октября 23:00, принятие и промоушн — 14 октября 23:00,
доказательства в Taskmarket — 16 октября 23:00.

## Почему не берём

| Факт | Что это значит |
| --- | --- |
| Рекорд `pinning` — **667 612 737** проверенных кандидатов/с (DPZZxlz, 17.09, +5.07%) | Нужно не «улучшить», а побить лучший результат в мире |
| В лидерборде **8 промоушнов за 2 дня**, все — агенты (GPT-5.6 Sol, Grok 4, Opus 5, Kimi K3, GPT-6 Astra, DeepSeek-V4-Flash) | Конкуренты итерируются на настоящих GPU по несколько раз в день |
| Локальная проверка требует NVIDIA GPU (`./setup.sh pinning`, `./benchmark.sh pinning`), раннеры — self-hosted RTX 4090 (`starkware-pinning-rtx4090`) | В песочнице фермы нет ни GPU, ни `nvcc`. Код можно написать, но **нельзя измерить** — а без измерения это лотерея |
| Правило «нулевой вклад» | Арендовать GPU нельзя (это плата вперёд), своего нет |
| Официальный рекорд считается только по официальному прогону Yukon | Наши локальные цифры (даже если бы были) не значат ничего |
| Отправка подписывается кошельком оператора и требует Yukon-аккаунта, привязанного к GitHub | Действия человека: регистрация, CLI, подпись, отправка |

Оценка: вероятность положительного прироста над рекордом, который агенты
обновляют несколько раз в день, — единицы процентов, а доля с одного очка в
общем пуле — несколько долларов. Это работа себе в убыток, поэтому фиксируем
отказ с причиной (команда `статус <id> dropped --note "..."`); вернуть в
очередь можно в любой момент.

используется тот, что привязан к площадке.

## Если всё-таки решаем попробовать (нужен свой NVIDIA GPU)

Тогда порядок такой — робот готовит код, человек запускает и отправляет:

1. Yukon: открыть yukon.org/qsb → Participate → вход через GitHub-аккаунт,
   он же должен быть связан с кошельком в заявлении.
2. Клонировать дорожку: `yukon clone eigenlabs/starkware-challenge/pinning`
   (и отдельно `subset` — разные чекауты).
3. Прочитать `README.md`, `benchmark.json`, `candidates/README.md`; правится
   только `candidates/pinning/` (или `candidates/subset/`).
4. Локальная проверка: `./setup.sh pinning` и `./benchmark.sh pinning`
   (нужен совместимый NVIDIA GPU; ранжирует только официальный прогон Yukon).
5. Заявление о кошельке — публичный Gist с GitHub-аккаунта, привязанного к
   Yukon (подставить handle и адрес):

   > For Taskmarket task
   > 0x5f596b1a81417834a4366655bd4e6194819f5404a62c919c6953ae9bc92860bc,
   > my Yukon solver `<handle>` designates Base wallet
   > `0x6E16fF195d8bbA5628F169BdFb3644655Ba2a8A8` to receive this bounty's rewards.

6. Отправка: `taskmarket task submit <TASK_ID> --file evidence.md` — из того же
   кошелька; в `evidence.md` по каждому заявленному результату: дорожка,
   submission ID, ссылка на публичный результат, время создания и промоушна,
   точный официальный счёт, ссылка на оценённый коммит и на артефакт прогона.

Полезные факты для кода (из публичного зеркала): правится только каталог
дорожки; интерфейс сборки фиксирован — `nvcc -O3 -DQSB_ZEROS_N=<N> -o <track>
<track>.cu -lcrypto -lm`, попадания пишутся в `results/<track>_hit_*.txt`;
скомпилированное считается частью прогона, поэтому сборка — в `setup.sh`.
Текущая продвинутая реализация и журналы исследований лежат в зеркале
(`candidates/pinning/RESEARCH.md`, `candidates/subset/TREE_INVERSE.md`) — это
состояние после промоушнов, то есть то, что надо побить.

# Как работать с фермой: ежедневный и недельный цикл

Документ про то, **как именно из фермы выжать деньги**. Он короткий, потому что
схема простая: находить дешёвое по времени и дорогое по оплате, не тратить часы
на проигранные задачи и измерять реальную ставку.

## Формула, по которой всё считается

```
доход ≈ (сумма награды × вероятность успеха) / затраченные часы
```

Ферма оптимизирует все три множителя:

- **сумма** — `audit_contests` даёт потолок в разы выше GitHub-bounty;
- **вероятность** — `triage` отсеивает задачи, где уже 30+ конкурентов
  (вероятность падает с 22% до 0.1%, и это не абстракция, а измерение);
- **часы** — плейбуки: повторяемые типы задач делаются по готовым шагам и
  чек-листу, а не с нуля каждый раз.

## Ежедневный цикл (10–15 минут)

```bash
python -m agent.main cycle      # сбор + триаж (проверка конкуренции)
python -m agent.main next       # что делать: топ по EV/час
python -m agent.main plan <id>  # план работ по выбранной задаче
```

1. `cycle` обновляет очередь и отсеивает уже оплаченные задачи.
2. `next` показывает только то, что стоит времени (по умолчанию EV/час ≥ $3).
   Всё, что ниже, уходит в раздел «не тратить время» — это не мусор, а защита
   от соблазна «ну тут же $700».
3. Выбрав задачу, запустите `plan`: подагенты соберут контекст, шаги, критерии
   готовности и типовые причины отказа. План сохраняется в `reports/`.
4. Работаете. Результат публикуете **вы** — ферма не пишет от вашего имени.

## Правила, которые экономят больше всего времени

1. **Проверяйте триаж до первой строки кода.** `python -m agent.main triage <id>`
   покажет число заявок `/attempt` и открытых PR. Если открытых PR больше
   одного — это не задача, а лотерея.
2. **Берите свежее.** Задача возрастом до 3 дней даёт +25% к оценке в ферме,
   потому что поле ещё пустое. Задача трёхнедельной давности с 20 конкурентами
   не стоит ничего.
3. **Одна задача — один PR.** Расширение объёма работ = второй круг ревью = ещё
   день без оплаты.
4. **PoC обязателен** там, где он требуется (аудит-контесты, веб-bug bounty):
   отчёт без воспроизведения отклоняют, и весь труд уходит в ноль.
5. **Не работайте бесплатно «на репутацию»** в задачах с наградой: репутацию
   даёт смерженный PR с оплатой, а не отзывчивость.

## Учёт времени: единственный способ узнать правду

```bash
python -m agent.main hours-add --channel github_bounties --hours 2.5 --id github:owner/repo#12
python -m agent.main analytics
python -m agent.main payout-add --channel github_bounties --amount 120 --evidence "PR #45 merged"
python -m agent.main payout-verify 1
```

`analytics` считает **эффективную ставку**: подтверждённый доход ÷ залогированные
часы. Пока выплат не было, ставка нулевая — и это правильный сигнал: значит,
пора менять канал или тип задач, а не работать больше.

Разделение «заявлено» и «подтверждено» сделано специально: сумма считается
доходом только после вашей проверки поступления денег.

## Недельный разбор (20 минут)

```bash
python -m agent.main analytics
python -m agent.main report      # отчёт в reports/
```

Смотрите три числа:

| Что смотреть | Хорошо | Что делать, если плохо |
|---|---|---|
| Эффективная ставка | ≥ $10/ч | Убрать дешёвые типы задач, перейти на контесты |
| Доля отказов триажа | 60–90% | Норма: рынок competitive. Если <30% — вы смотрите на старые задачи |
| EV/час конвейера | ≥ $15/ч | Поднять долю `audit_contests` и площадок для агентов |

## Как поднять потолок дохода (по порядку отдачи)

1. **Специализация.** Выберите 1–2 типа задач (например, тесты + интеграции) и
   доведите их до шаблона. Плейбуки в `agent/playbooks.py` — заготовка, свои
   шаги можно дописать после первых десяти задач.
2. **Аудит-контесты.** Самый большой EV/час: $20–$45 против $0–$3 на GitHub.
   Порог входа — Solidity. Начните с чтения двух-трёх разборов прошлых
   контестов и воспроизведения чужих находок в Foundry.
3. **Площадки для агентов** (AgentHansa и подобные): $20–$50 за задачу, выплата
   в USDC, низкий порог. Хороший способ добить месяц до $500, пока контесты не
   начали платить.
4. **Репутация → приватные приглашения.** После нескольких валидных находок
   платформы приглашают в закрытые контесты, где меньше участников и выше
   выплаты. Это и есть переход к $5,000+/мес.
5. **Дисциплина отказов.** Самая дорогая привычка — дорабатывать задачу, которую
   уже выиграл кто-то другой. Триаж существует ровно для этого.

## Чего ферма не сделает за вас

- не напишет PR и не опубликует его от вашего имени (`submit_deliverable_human_approved` требует человека);
- не подтвердит доход без доказательства (`payout-verify` — ручной шаг);
- не найдёт уязвимость в контракте — она подготавливает площадь работ, а находка
  остаётся интеллектуальной работой;
- не даст схем «без вложений и без работы»: таких не существует, и все
  популярные варианты перечислены в `docs/PLATFORMS.md` с причинами отказа.
